Gmail Multi MCP

A personal plugin for Claude Desktop that connects several Gmail accounts.

Privacy policyTerms of use

Gmail Multi MCP runs on the user's own computer as a local MCP server. It lets Claude search, read, draft, send and organise email in the Gmail accounts that the user connects. It is a private tool of Krzysztof Jabłoński and is not offered as a public service.

Privacy policy

Last updated: 23 October 2026

What data the app uses. After you sign in with Google, the app reads and changes Gmail data only when you ask Claude to do so: message headers, bodies, attachments, labels and drafts of the accounts you connect.

Where the data goes. The app runs only on your computer. It talks directly to Google's Gmail API. There is no server operated by the developer, and the developer receives no data. Email content is passed to the Claude Desktop app on your computer so that Claude can answer your request; Anthropic's privacy policy applies to that part.

Storage. The app stores the OAuth refresh token of each account in the macOS Keychain (on Linux, in a file readable only by you). It stores the list of connected email addresses on your computer. It does not store email content, except attachments that you ask it to save to your Downloads folder.

Sharing. The app does not sell, share or transfer Google user data to anyone. It does not use the data for advertising, and it does not use it to train AI models.

Google API Services User Data Policy. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removal. You can disconnect an account at any time with the remove_account tool, which revokes the token at Google and deletes it from your computer, or at myaccount.google.com/permissions.
